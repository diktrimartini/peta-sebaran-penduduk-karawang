# Analisis Spasial Sebaran Penduduk Kabupaten Karawang

## Objektif Proyek
Proyek ini bertujuan untuk latihan memetakan dan menganalisis sebaran jumlah penduduk tingkat kecamatan di Kabupaten Karawang. Visualisasi ini dirancang untuk mengidentifikasi konsentrasi populasi sehingga dapat mengetahui daerah yang memiliki jumlah penduduk terbanyak serta pemetaan wilayah strategis.
